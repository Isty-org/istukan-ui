# Istukan UI — установщики

Здесь публикуются только подписанные установщики Isty Control — Kaneo и служебный файл обновления `latest.json`.

Исходный код, история разработки, подключения Kaneo, API-ключи и данные пользователей находятся в отдельном закрытом репозитории и в этот репозиторий не копируются.

## Установка

Откройте страницу [релизов](https://github.com/Isty-org/istukan-ui/releases) и скачайте файл для своей системы:

- Windows: установщик `.exe`;
- Mac с процессором Apple Silicon: `.dmg` с пометкой `darwin-aarch64`;
- Mac с процессором Intel: `.dmg` с пометкой `darwin-x86_64`.

После первой установки приложение само предложит подписанное обновление, когда появится новая версия. Оно не хранит и не запрашивает учётную запись GitHub.

## Проверка подлинности

Каждый пакет обновления подписывается отдельным ключом Tauri до загрузки сюда. Настольное приложение проверяет подпись до установки. Возможность записывать файлы в этот репозиторий сама по себе не позволяет выпустить доверенное обновление без закрытого ключа подписи.
